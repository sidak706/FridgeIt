# FridgeIt 🥕🍅

FridgeIt was inspired by the increasing food waste crisis and the need for smarter food management. We aimed to empower users to track their food items and reduce waste through AI-driven insights. By allowing users to input items going into their fridge or freezer, FridgeIt leverages generative AI to calculate and notify them of expiry dates, ensuring they consume food at its peak freshness. This not only helps save money 💰 but also contributes to a more sustainable lifestyle 🌍. The project is a step towards creating a more efficient kitchen 🍽️ and a healthier planet 🌱!

---

## 🚀 Features

- Track food items in your fridge or freezer 🥶  
- AI-driven expiry date predictions 🔮  
- Receive email reminders 📧 about items approaching expiration  
- Simple, user-friendly interface 🖥️  

---

## 🛠️ Installation

1. **Clone this repository** to your local machine:

    ```bash
    git clone https://github.com/your-username/fridgeit.git
    ```

2. **Navigate to the project directory**:

    ```bash
    cd fridgeit
    ```

3. **Install the required dependencies**:

    ```bash
    pip install -r requirements.txt
    ```

4. **Create a `.env` file** in the root of the project and add your SendGrid API key:

    ```env
    SENDGRID_API_KEY=your_sendgrid_api_key
    ```

    > ⚠️ You can get your SendGrid API key by signing up on [SendGrid](https://sendgrid.com/) and creating an API key in your account settings.

5. **Run the application**:

    ```bash
    python main.py
    ```

6. **Open the link generated by Flask** in your browser 🌐. Create an account, and start adding items to your fridge 🍎🥛.

7. **Email yourself the list of items** to get a nicely formatted summary of what’s expiring 📩.
